💡 Il significato di Δ nella geometria analitica:

  • Δ > 0: La parabola interseca l'asse x in due punti distinti (secante).
  • Δ = 0: La parabola tocca l'asse x in un solo punto, che è esattamente il suo vertice (tangente).
  • Δ < 0: La parabola non tocca mai l'asse x (esterna: sempre positiva se a > 0, sempre negativa se a < 0).

Guida Rapida di Algebra

Tassonomia e procedimenti per le equazioni di secondo grado

Tipo Forma Metodo Risolutivo Soluzioni
Monomia ax² = 0 Divisione per a x₁ = x₂ = 0
Spuria ax² + bx = 0 Legge annullamento prodotto: x(ax+b)=0 x₁=0, x₂=-b/a
Pura ax² + c = 0 x² = -c/a ➔ estrazione radice x = ±√(-c/a) (se -c/a ≥ 0)
Completa ax² + bx + c = 0 Formula generale del discriminante Δ x = (-b ± √Δ) / 2a
Formule Indispensabili

Formula Ridotta (quando b è pari, b = 2k):

Δ/4 = (b/2)² - ac  ➔  x = (-b/2 ± √(Δ/4)) / a

Relazioni di Viète (Somma e Prodotto delle Radici):

Somma: s = x₁ + x₂ = -b / a

Prodotto: p = x₁ · x₂ = c / a

Scomposizione del Trinomio di 2° Grado:

ax² + bx + c = a(x - x₁)(x - x₂)
